## 完成定义

聊天页能基于现有 ReAct 事件展示安全、简洁的行动轨迹；原始思考链、工具参数和完整返回值不进入轨迹；测试、构建和变更文档均更新。

## 范围与前置条件

- 范围：客户端事件解析、状态归约、聊天展示、测试和文档。
- 前置条件：现有 ReAct 事件协议和 `showReactSteps` 设置可用。
- 不涉及：数据库、服务端端点、模型提示词和持久化历史轨迹。

## 风险与依赖

- 事件可能来自 HTTP SSE 或 Electron IPC，解析层必须保持两者行为一致。
- 工具摘要可能为空，必须有稳定的通用文案。
- GitNexus CLI 当前 Node 18 不兼容，需在验证记录中标注影响分析降级。

## 验证方式

- 客户端 Vitest：事件映射、状态终态、思考/参数/结果过滤。
- `npm run build`：服务端编译与客户端生产构建。
- `git diff --check`：检查格式问题。
- 文档检查：追溯项、TP 状态、索引与实现一致。
