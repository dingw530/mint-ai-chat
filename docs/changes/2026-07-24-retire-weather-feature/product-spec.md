# 产品规格：移除天气功能

## 文档信息

| 属性 | 值 |
|---|---|

| 状态 | 已完成 |

## 背景与目标

天气 Agent 及其 QWeather 集成已经不再属于产品核心能力。此次迭代将天气能力从服务端、客户端、Electron 端点清单和配置中完整下线，同时保留通用 Agent、自定义 Agent、MCP、Wiki 和普通聊天能力。

## 范围

### 本次要做

- 移除天气 Agent、天气工具、QWeather 服务、天气端点及相关配置。
- 为已有数据库增加迁移：删除天气 Agent，并解除会话上的天气锁定。
- 清理客户端天气入口、图标、示例文案和测试残留。

### 本次不做

- 不修改历史变更文档和历史索引记录。
- 不改变通用聊天、Agent 路由、自定义 Agent、MCP、Wiki 或其他工具行为。

## 验收标准

- **AC-001**：新数据库只创建仍受支持的内置 Agent，不创建天气 Agent。
- **AC-002**：旧数据库执行迁移后，天气 Agent 被删除，锁定天气 Agent 的会话恢复为未锁定。
- **AC-003**：天气工具、QWeather 配置、天气服务、天气端点和 Electron manifest 条目均不可用。
- **AC-004**：通用 Agent、自定义 Agent、MCP、Wiki 和普通聊天继续可用。
- **AC-005**：构建、Lint、单元测试和 Harness 检查通过。
