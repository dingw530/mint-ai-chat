## 背景与目标

为 Mint 增加一个可独立部署到 GitHub Pages 的产品介绍站，让访客快速理解产品定位、核心能力和开源入口，并能够在中文和英文之间切换。

## 范围

### 本次要做

- 新增独立 `website` workspace 和静态构建产物。
- 提供单页产品介绍、能力分区、开源行动入口和中英双语切换。
- 增加 GitHub Pages 构建与部署 workflow。

### 本次不做

- 不接入 Mint 服务端 API、登录、聊天或数据库。
- 不修改主客户端的路由和业务功能。
- 不引入新的运行时依赖。

## 验收标准

- **AC-001**：访问站点首页可以看到 Mint 的双语产品介绍、核心能力、开源入口和页脚信息。
- **AC-002**：点击语言切换后，页面主要文案在中文和英文之间切换，并保留用户选择。
- **AC-003**：站点在桌面和窄屏视口下均可阅读，关键按钮和导航链接可用。
- **AC-004**：`npm run build:website` 生成可直接部署的 `website/dist` 静态文件，且不依赖服务端。
- **AC-005**：GitHub Actions 能构建 `website/dist` 并部署到 GitHub Pages。
