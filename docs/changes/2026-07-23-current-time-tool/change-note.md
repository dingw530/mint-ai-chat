# 当前时间工具

## 目标

让模型在涉及“今天”、当前日期或当前时间时，能够通过工具获取真实的执行时刻，避免使用模型训练数据中的日期。

## 范围

- 新增无参数 `get_current_time` 内置工具。
- 返回 UTC ISO 时间、Unix 时间戳、服务器时区、本地日期、本地时间和可读时间。
- 不修改数据库、API 端点或前端代码。

## 验收

- 工具定义会随内置工具提供给模型。
- 每次执行都读取当前系统时间。
- 返回的日期和时间字段格式明确，包含时区信息。

## 验证

- `server`: CurrentTimeTool 定向测试通过。
- `server`: TypeScript build 通过。

## 风险

返回的是服务端系统时间；若服务器系统时区配置错误，本地时间字段会反映该配置，但 UTC 时间仍可用于校验。
