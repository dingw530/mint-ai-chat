# 产品规格：Wiki 摄入质量修正

## 问题

- 单文件上传同时保存原始归档和规范化副本，导致 `sources/` 出现重复文件，日期前缀还可能重复。
- 长文输出受固定 token 上限影响，通常被压缩成一篇页面。
- 分类提示缺少边界，案例型文章容易全部归入“实践”。

## 目标

- 单文件只保留一份 source 原始归档，多文件和文本/URL摄入保留组合快照。
- 长文按独立知识主题拆分为多篇页面。
- 页面分类依据自身主题在实践、方法论、思维模式、概念之间选择。

## 验收标准

- 已归档文件作为单文件摄入的 `sourceFile`，不再生成同名规范化副本。
- 归档文件名最多包含一个日期前缀。
- 长文编译输出上限提高，提示词明确要求 2-6 篇页面。
- TypeScript 编译和 Wiki 相关测试通过。
